# 短视频内容工作台（榜单视频生成器）

一个跑在本机的竖屏短视频生产工具：**把一段文字或一张图片，变成一条带动态标题、清单面板、配音和 BGM 的成品视频**。

前端是一张单文件 HTML（Canvas 2D 逐帧渲染），后端是一个只监听 `127.0.0.1` 的 Python 小桥，负责 TTS、大模型调用、飞书多维表格、素材库和 ffmpeg 合成。没有账号体系、没有云服务、没有遥测——素材和成品都在你自己的目录里。

```
原文 / 图片 / 飞书表格行
        │
        ├─► 内容二创（本地 GGUF → Ollama → 在线 API）
        │        └─ 标题1 / 标题2 / 胶囊 / 清单正文 / 开场配音文案
        │
        ├─► 队列（逐条：背景 / 音乐 / 字体 / 动画 / 时长）
        │
        └─► 导出 ── 离线帧序列 + ffmpeg ──► 导出/2026-10-26/*.mp4
                  └ 失败回退实时录制（MediaRecorder）
```

---

## 功能

**画面**
- 7 套标题版式预设（①②…⑦，来自「标题样式图鉴」的复刻实现），可与副标题、胶囊自由组合
- 8 种标题入场动画（重锤、逐字点亮、遮罩揭示、交错、翻转、故障、碎片聚合、回弹）
- 5 种正文动画（逐条递进、打字机、整行擦除、卡片滑入、关键词强调）
- 关键词强调三种样式（底纹+放大 / 底纹 / 脉冲），`{}` 标记重点
- 每条视频可独立设置背景图、BGM、字体、字号、间距、配色；支持随机换字体避免雷同
- 分辨率 / 帧率 / 总时长可配（默认 1080×1920 30fps）

**声音**
- Edge-TTS 配音（微软在线语音，免费，7 种中文音色），带毫秒级时长回填，视频自动按语音长度拉伸
- 可选 Qwen3-TTS 本地推理（ComfyUI 环境，文字描述音色，需显卡）
- 配音时 BGM 自动降到较低音量（ducking）

**批量**
- 队列持久化（刷新页面不丢）、逐条编辑、整批导出
- 导出路径按日期 / 类别自动归档

**AI 二创**
- 粘贴原文，或丢一张图（本地视觉模型 / 在线视觉 API 均可）
- 三级推理回退：本地 GGUF（ComfyUI 自带 llama.cpp）→ Ollama / LM Studio → 在线 OpenAI 兼容 API（DeepSeek、豆包、通义…）
- 收件箱：把 `.txt` / `.md` / 图片丢进 `inbox/`，自动生成文案并入队
- 支持抖音分享链接解析（yt-dlp，仅取元数据）
- 支持视频/音频转文字（桥的 `/media/extract`，可选装 faster-whisper 或 openai-whisper，需 ffmpeg）

**飞书（可选）**
- 从多维表格读「视频清单」，直接把行变成待出片队列
- 导出后回写「生成状态」（正在处理 / 已生成）
- 配合「空闲自动导出」可做到无人值守：表格里填原文 → 自动二创 → 自动出片

## 环境要求

| 依赖 | 是否必需 | 说明 |
|---|---|---|
| Windows 10/11 | 推荐 | 启动脚本、路径探测按 Windows 写的；macOS/Linux 可手动跑 Python |
| Python 3.9+ | 必需（用桥时） | 只用标准库也能跑，TTS / 二创需要额外包 |
| Chrome / Edge | 必需 | 依赖 `captureStream` + `MediaRecorder` |
| ffmpeg | 强烈建议 | MP4 合成、音视频转码；放 `ffmpeg\ffmpeg.exe` 或加入 PATH |
| `edge-tts` | 配音必需 | `pip install edge-tts`，在线调用，无需显卡 |
| ComfyUI Desktop | 可选 | 提供本地 Qwen3-TTS、媒体库、GGUF 兜底 |
| Ollama + `qwen2.5vl:7b` | 可选 | 推荐的内容二创引擎，8G 显存可全量上卡 |
| `yt-dlp` | 可选 | 抖音链接解析 |
| `faster-whisper` | 可选 | 视频转文字 |
| 飞书自建应用 | 可选 | 多维表格读写，见下方配置 |

> 不装 ComfyUI 也能完整出片，只是失去「本地 Qwen3-TTS」「媒体库随机背景/BGM」「GGUF 兜底」这几项。

## 快速开始

### 方式一：一键启动（Windows）

1. 双击 **`启动生成器.bat`**
   - 会自动拉起本地桥（`127.0.0.1:8677`），再打开工作台页面
   - 想连 ComfyUI 的话用 **`start_bridge.ps1`**，它会先探测 ComfyUI 环境、必要时启动 ComfyUI（8188）
2. 浏览器打开 **`榜单视频生成器.html`**
3. 点右上角 **⚙ 设置** 配好规格、音色、AI 模型（能跑就是配好了，可以跳过）
4. 点 **🔮 内容二创** 粘一段文字 → 生成文案 → 加入队列 → **📤 批量导出**

### 方式二：手动启动

```bash
# 1. 启动本地桥（可选，但二创 / 配音 / 飞书 / 导出都依赖它）
python comfy_bridge.py
# 或指定端口与上游 ComfyUI
python comfy_bridge.py --port 8677 --upstream http://127.0.0.1:8188

# 2. 直接用浏览器打开页面
#    榜单视频生成器.html
```

桥掉线自动重启：双击 **`桥守护.bat`**（无窗口版用 `启动桥守护.vbs`）。

### 第一次出片的最短路径

1. 打开页面 → 顶部 **🔮 内容二创**
2. 粘贴一段素材原文 → **✨ 生成文案**
3. **➕ 加入队列**
4. **📤 批量导出** → 成品落在 `导出/<日期>/`

## 目录结构

```
视频生成器/
├─ 榜单视频生成器.html    # 工作台：UI + Canvas 渲染 + 队列 + 导出（单文件，无需构建）
├─ comfy_bridge.py        # 本地桥：TTS / LLM / 飞书 / 素材库 / ffmpeg 合成（默认 8677）
├─ content_rewrite.py     # 内容二创引擎：原文/图片 → 标题·胶囊·正文·配音文案
├─ start_bridge.ps1       # 一键启动（探测 ComfyUI，拉起 8188 + 8677，打开页面）
├─ 启动生成器.bat          # 启动桥 + 打开页面（不依赖 PowerShell）
├─ 桥守护.bat              # 桥掉线自动重启
├─ 启动桥守护.vbs          # 上面那个的无窗口启动器
├─ config.example.json    # 配置样例（复制为 config.json 使用）
├─ font/                  # 字体（.ttf/.otf/.woff/.woff2/.ttc）
├─ bgm/                   # 背景音乐（.mp3/.wav/.m4a/.aac/.ogg/.flac）
├─ images/                # 背景图（.png/.jpg/.jpeg/.webp/.bmp）
├─ ffmpeg/                # 可选：把 ffmpeg.exe 放这里
│
└─ 运行时自动生成（已在 .gitignore）：
   config.json            # 设置项 + 飞书凭证 + API Key（明文，勿提交）
   bridge.log             # 运行日志（含本机路径）
   tts_cache/             # 配音 mp3 缓存
   inbox/                 # 二创收件箱（丢文件即处理）
   rewrite_pending.json   # 收件箱生成结果
   导出/YYYY-MM-DD/        # 成品视频
```

**素材全部跟着目录走**：换电脑时整个文件夹拷过去即可，不需要安装字体、不需要重新配素材路径。

## 配置与密钥（重要）

`config.json` **不在仓库里**。程序第一次在设置面板点「保存设置」时会自动生成它，内容包括：

- 飞书自建应用的 `app_id` / `app_secret` / 多维表格 `app_token` / `table_id`
- 在线大模型的 `api_key`（如 DeepSeek 的 `sk-...`）
- 界面与导出相关设置

这些都是**明文**存的。`.gitignore` 已经排除了它，但请务必记住：

```bash
git status --porcelain   # 提交前扫一眼，不该出现 config.json / *.log / tts_cache
```

想从样例开始：

```bash
cp config.example.json config.json
```

### 飞书接入步骤

1. [飞书开放平台](https://open.feishu.cn) → 创建企业自建应用 → 复制 `app_id` / `app_secret`
2. 给应用添加「多维表格」权限：`bitable:app`、`bitable:record` 等
3. 页面 **⚙ 设置 → 飞书与本地服务**：填 `app_id` / `app_secret`，粘贴多维表格链接（`table_id` 可留空自动解析）
4. 在飞书里把该应用加为这张表的**协作者**（至少可编辑），否则会 403
5. 点顶部 **🔧 连接并准备表**，再点 **📥 读飞书清单**

表格列名约定（**程序不会自动建表或建列**，缺的列留空即可；候选列名会自动匹配）：`原文素材`、`标题1`、`标题2`、`胶囊`、`内容`、`配音文案`、`生成状态`、`人工审核`。

- 只取「`生成状态` 为空 + `人工审核` 已勾选」的行（表里没有「人工审核」列时不按它过滤），导出后状态写为「已生成」
- 只填了「原文素材」的行会自动二创补齐标题与正文；`标题1` / `内容` 任一非空视为已有成品，不会覆盖
- 文件名取 `<表序号>_<标题1>.mp4`，同级重名自动追加 `_1` / `_2`

## 联网说明 / 隐私

工具本身完全本地运行，桥只绑定 `127.0.0.1`，不对局域网或公网开放。**只有你主动启用的功能才会出网**：

| 功能 | 去向 | 发出什么 |
|---|---|---|
| Edge-TTS 配音 | 微软 Edge 语音服务 | 要朗读的文本 |
| 在线大模型二创 | 你配置的 API 端点 | 原文 / 图片 |
| 抖音链接解析 | 抖音（经 yt-dlp） | 视频链接 |
| 本地 Ollama / GGUF | 不出网 | — |
| 飞书集成 | open.feishu.cn | 表格内容 |
| 字体 / BGM / 背景 | 不出网 | — |

不收集任何使用数据，没有埋点。**唯一的个人信息**是运行日志里的本机路径（`bridge.log`，已忽略）。

## 本地桥 API 一览

所有接口都在 `http://127.0.0.1:8677`，前端通过它工作。想接自己的脚本可以直接调：

| 方法 | 路径 | 用途 |
|---|---|---|
| `*` | `/*` | 原样代理到 ComfyUI（补 CORS 头） |
| `POST` | `/tts` | Edge-TTS 生成 mp3 并缓存，返回时长 |
| `GET` | `/tts/audio?id=` | 取缓存的配音 |
| `POST` | `/qwen/tts` | 本地 Qwen3-TTS，返回 wav |
| `POST` | `/voice` | 生成 18~22 字开场配音文案 |
| `POST` | `/translate` | 翻译 |
| `POST` | `/llm` | OpenAI 兼容转发（上游失败回退本地） |
| `POST` | `/rewrite` | 原文/图片 → 标题·胶囊·正文 |
| `GET` / `POST` | `/rewrite/pending`·`/ack`·`/scan`·`/warm`·`/status` | 收件箱队列控制 |
| `POST` | `/douyin/parse` | 分享链接 → 标题/简介/作者 |
| `POST` | `/media/extract` | 视频/音频 → 文字 |
| `GET` | `/media_lib`·`/media_file` | 素材库列表 / 读取（路径穿越已防护） |
| `POST` | `/save_file` | 保存成品到 `导出/日期/[类别]/` |
| `POST` | `/video/compose` | 帧流 + ffmpeg 合成 MP4 / WebM |
| `GET` / `POST` | `/config` | 读写 `config.json` |
| `POST` | `/feishu/*` | 探测字段 / 写行 / 读行 / 更新状态 |

## 导出说明

- **快速导出（默认）**：逐帧渲染 JPEG → 桥交给 ffmpeg 合成，速度不受实时播放限制，需要 ffmpeg
- **实时录制（回退）**：`MediaRecorder` 录画布，无需 ffmpeg，但耗时等于视频时长，且浏览器后台标签会掉帧——导出时请保持页面在前台
- 产物命名 `<序号>_<标题1>.mp4`，按 `导出/<日期>/<类别>/` 归档，重名不覆盖

## 常见问题

**双击 bat 一闪而过**
装 Python 3 并勾选「Add to PATH」，或直接用 `python comfy_bridge.py` 看报错。

**页面显示「链接不上本地服务」**
桥没起来。跑 `启动生成器.bat`，浏览器访问 `http://127.0.0.1:8677/media_lib` 应返回 JSON。端口被占用时用 `--port` 换一个，并同步改设置里的「本地桥服务地址」。

**导出的 MP4 是黑屏或 0 字节**
优先检查 ffmpeg 是否存在；再确认导出期间页面保持前台。关闭硬件加速有时能解决 `captureStream` 兼容问题。

**二创很慢**
第一次要加载模型（20~60 秒），之后热态约 1~2 秒。打开二创窗口会自动预热。

**字体没生效**
字体放 `font\` 后等 8 秒（自动检测），或点设置里的「刷新字体库」。

**飞书 403 / 表不存在**
应用没被加为表格协作者，或缺少 `bitable:*` 权限，或 `app_token` 填错。

**提示「Prompt 文件不存在」**
见下一节。

## 关于提示词文件

二创质量取决于两个提示词文件，它们**没有随仓库发布**（属于作者的内容方法论）：

- `内容生成prompt.txt` —— 清单正文规范
- `配音文案prompt.txt` —— 开场配音规范

缺失时程序会退到内置的简短兜底提示词，**功能正常但文案质量明显下降**，日志里会有 warning。
如果你 fork 了自己用，把这两个文件放进程序根目录即可生效（改文件即时刷新，不用重启）。

## 素材与授权

仓库里的 `font/`、`bgm/`、`images/` 仅为**演示素材**，帮助项目跑起来，**不代表可以商用**：

- 中文字体多为商业授权字体，二次分发/商用前请自行确认授权，或替换为[思源黑体](https://github.com/adobe-fonts/source-han-sans)等开源字体
- BGM 请替换为你有权使用的音频
- 背景图请使用自己生成或已获授权的素材

如果你要 fork 发布，建议把这三个目录加进 `.gitignore`，只保留目录说明文件。

## 已知限制

- 面向 Windows 开发，其他平台需手动处理启动脚本与字体路径
- 桥没有鉴权，仅适合本机单用户使用；`Access-Control-Allow-Origin: *` 意味着本机任意网页都能调用它，长期开着的机器建议改白名单
- 一条视频的清单正文控制在 3~5 条、140 字以内效果最好（字体与面板的版式约束）
- 自动出片依赖飞书轮询（约 5 分钟一次），不是实时队列
